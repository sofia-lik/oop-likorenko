Как запустить программу:
1. Откройте проект в Visual Studio
2. Нажмите клавишу F5 или кнопку "Запуск" в верхней панели
3. Откроется окно "Мои задачи"
4. Файл `tasks.json` создастся автоматически при первом добавлении задач
Файл с задачами сохраняется в папке bin\Debug\net8.0-windows\tasks.json.

Чек-лист:

-Основные задания:

1. Модель: классы TodoItem и TodoList с закрытыми полями (private), изменение только через методы;
2. Окно: поле ввода названия, поле даты, кнопка "Добавить", список задач с отметками выполнения;
3. Операции: выполнить, переименовать, удалить — список обновляется сразу;
4. Ошибки: проверка пустого названия, проверка выбора задачи;
5. Сохранение: задачи сохраняются в JSON (tasks.json) и загружаются при запуске.

-Дополнительные задания: 

1. Фильтр "Все / Активные / Выполненные" — кнопки переключают отображение;
2. Сортировка "По сроку / По названию";
3. Логика реализована методами класса TodoList (Filtered(), SetFilter(), SetSort());
4. Поле поиска фильтрует список по мере ввода текста;
5. Задачи с истёкшим сроком выделены красным цветом;
6. Выполненные задачи отображаются серым цветом;
7. Проверка истёкшего срока реализована методом IsOverdue() в TodoList.

Как устроен проект:

-Program.cs — точка входа, запускает MainForm;

-MainForm.cs — представление (рисует элементы управления (кнопки, поля, список), обрабатывает клики и ввод пользователя, вызывает методы модели, не содержит бизнес-логики);

-TodoList.cs — общая модель (хранит список задач в памяти, фильтрация, сортировка, поиск, сохранение и загрузка из JSON);

-TodoItem.cs — модель одной задачи (название, статус выполнения, срок, методы: Complete(), Rename() с валидацией, инкапсуляция: поля private, доступ через свойства).
