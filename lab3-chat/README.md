## Чек-лист

Общий чат: сообщение, отправленное одним участником, получают все. У каждого сообщения есть время.

Список «Онлайн» обновляется, когда кто-то входит или выходит.

Личные сообщения: выбрать адресата в списке «Онлайн» и отправить. Сообщение видят только двое (отправитель и адресат), в ленте оно выделено цветом. Чтобы писать всем, выбрать в списке «Всем».

История: сервер сохраняет общие сообщения в файл и отправляет новому клиенту последние 20, в том числе после перезапуска сервера. Личные сообщения в историю не попадают.

Если сервер не отвечает, окно показывает понятное сообщение (таймаут подключения 5 секунд). Если ник занят, сервер сообщает об этом. Если сервер пропал во время работы, в ленте появляется «Соединение с сервером потеряно».

## Как устроен проект 

ChatMessage.cs - Протокол: сообщение и его перевод в строку JSON и обратно.

ChatClient.cs - 	Сетевой клиент: подключение, чтение в фоновом потоке, событие MessageReceived.

Program.cs - Точка входа: запуск чат-сервера.

ChatServer.cs - Приём подключений, общий список клиентов под lock, рассылка, личные сообщения, история.

ClientHandler.cs - Обработчик одного клиента (свой ник, свой поток).

LoginForm.cs - Окно входа: сервер, порт, ник.

MainForm.cs - Окно чата: лента, список онлайн, поле ввода.
