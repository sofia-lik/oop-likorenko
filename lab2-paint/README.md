Открыть Visual Studio и нажать F5.

Выбираем инструмент: 

Линия, карандаш, эллипс, прямоугольник; выбираем цвет; задаем толщину; чтобы нарисовать фигуру, зажимаем левую кнопку мыши и тянем; фигуру можно выделить и переместить; можно удалить выделенную фигуру, нажав delete; есть экспорт (кнопка PNG); кнопки "Сохранить", "Открыть" (JSON).


Чек-лист:

Окно. Холст, выбор инструмента, цвета и толщины. Выбранный инструмент виден.

Фигуры. Линия, прямоугольник, эллипс рисуются протягиванием с предпросмотром в любом направлении. Карандаш рисует кривую.

Иерархия. Абстрактный Shape, у каждой фигуры свой Draw. Рисунок рисуется одним циклом без проверки типа фигуры.

Отмена и очистка. Ctrl+Z убирает последнюю фигуру, «Очистить» убирает все. Это методы Drawing.

Файл. Сохранение в JSON и открытие с восстановлением всех фигур, цветов и толщин. Объект нужного класса по типу из файла создаёт фабрика: одно место на всю программу.

Дополнительно: Выделение фигуры щелчком, перемещение мышью, удаление клавишей Delete.Отмена и повтор (Ctrl+Z, Ctrl+Y) через паттерн Команда. Экспорт рисунка в PNG.


Как устроен проект:

Shape (абстрактный): общее для фигур (точки, цвет, толщина), абстрактные draw и contains.

LineShape, RestShape, EllipseShape: свои draw и contains.

PensilShape: хранит список точек, переопределяет MoveEnd, Move, Box.

Drawing: список фигур.

ShapeFactory: единственное место, где по типу создается нужный класс.

ICommand, History: паттерн "Команда", стеки отмены и повтора.

MainForm: окно, инструменты, мышь.
